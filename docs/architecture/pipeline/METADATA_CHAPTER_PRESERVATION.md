# Metadata and Chapter Preservation

This document details the strategies and FFmpeg mapping rules used to preserve subtitles, chapters, and camera metadata in `silukman_video_enhancer`.

---

## 1. Overview & Purpose

Modern video files (such as `.mkv` or `.mp4` containers) contain complex metadata alongside the core video and audio tracks, including:
*   Chapters (navigation indexes).
*   Subtitles (timed text tracks).
*   Camera tags (rotation, creation date, exposure, color primaries).

During enhancement, standard converters often strip this data. To prevent data loss, the pipeline incorporates a metadata mapping and copying pipeline.

---

## 2. Preservation Architecture

The preservation workflow operates during the final re-muxing stage of the video pipeline:

```text
Source Video Metadata
       │
       ▼ [Extract & Format]
FFmpeg Metadata Map Parameters (Subtitles, Chapters, Global Tags)
       │
       ▼ [Apply to final Mux]
Final Output Mux (Unified Container with intact original metadata)
```

---

## 3. FFmpeg Mapping Rules

The pipeline uses specific mapping arguments to copy metadata blocks:

### A. Subtitle Copies
Subtitles are mapped directly from the original source file to the final output file without decoding:
```bash
-map 0:s? -c:s copy
```
*Note: The `?` makes the command optional, so it succeeds even if the source file contains no subtitle tracks.*

### B. Chapter Copying
FFmpeg by default copies chapters if they are present in the input file. To guarantee chapter mapping, we explicitly pass the global metadata flag:
```bash
-map_metadata 0
```

### C. Chapter and Track Exclusions
If the user requests maximum compatibility or wants to prune attachments, the `--no-metadata` flag disables the mapping arguments, generating a clean container.

---

## 4. Configuration

Preservation is enabled by default and can be controlled via the configuration options:
*   `--no-metadata`: Disables chapters, subtitles, and tag mapping.

---

## 5. Verification

The mapping arguments generated by the configuration helpers are validated in:

```bash
python3 -m unittest tests.test_phase1_completion
```
Tests check that `-map 0:s?` and `-map_metadata` are formatted correctly in the final FFmpeg command list.
